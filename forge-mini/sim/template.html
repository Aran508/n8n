Eight tools, two racks, one bit block

Tools hang through holes in a raised shelf, like a reamer stand. Neighbouring arms share a rack: arm 1 and arm 3 use the left one, arm 2 and arm 4 the right one. The spindle picks its cutters from the bit block, so the same tool reams, drills, chamfers or drives screws.

The tool changer

Every wrist ends in the same coupler, and every tool carries the matching plate. The arm lowers onto a tool in the rack, an SG90 turns a cam to lock it, and the ESP32 reads the tool's ID resistor before the arm leaves the rack. A wrong or missing tool stops the run.

±0.05 mmrepeatability of 3 balls in 3 V-grooves
22 mmwrist axis to coupler face
10 gcoupler on the arm, with magnets
  1. Arm lowers onto the tool with the latch open. The balls drop into the grooves and the magnet pulls the plates flat.
  2. The latch servo turns 85°, and its hook locks under the tool plate.
  3. The ESP32 reads the ID pin. A gripper reads 1 kΩ, the spindle 10 kΩ, nothing at all reads open.
  4. The SIG pin now drives that tool: gripper jaw, pump, spindle speed or glue plunger.
  5. To return a tool, the arm lowers it into its slot, opens the latch and lifts away.

Arm design

All four arms are identical: base yaw, shoulder, elbow and wrist, with the tool always pointing straight down. The tool's length becomes the last link, so the kinematics change with every tool change and the planner keeps track.

How the code fits together

The AI never drives a motor. It writes a recipe, the planner proves it safe in this simulation, and only then does the ESP32 move servos. The e-stop and watchdog sit underneath everything.
